Инструкция
после запуска можно запустить сваггер по ссылке
http://localhost:8080/swagger/index.html

в сваггере:
* /tasks/create - создать задачу  
* /tasks/{id}/addFile - добавить URL файла
* /tasks/{id}/status - проверить статус задачи
для проверки статуса и одновременной загрузки нужно запрос выполнять не в сваггере, а в отдельной странице, чтобы запустилась загрузка и отобразился статус задачи

Для смены настроек редактируется файл ./config/dev.yaml

Заметки
swag init -g cmd/main.go
